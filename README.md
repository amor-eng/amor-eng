## About

I study Mathematics and Computing, and I spend most of my engineering time building systems software in modern C++23 — primarily in two areas: numerical computing libraries and low-latency trading infrastructure. Both projects are developed incrementally, in public, with an emphasis on correctness, clean architecture, and understanding every layer of the system rather than depending on it as a black box.

My broader interests sit at the intersection of systems programming, numerical methods, and quantitative finance: the kind of engineering that sits underneath research and trading systems rather than the applications built on top of them.

## Current Focus

- Building **Neuroforge** sprint by sprint — currently working through the core Matrix library
- Competitive programming, with ICPC as the current preparation target
- Coursework and independent study in machine learning
- Mathematics for quantitative finance (probability, stochastic processes, optimization)

## Engineering Philosophy

- Build from first principles — understand a system by implementing it, not by importing it
- Learn by implementing, even when a mature library already exists
- Favor clean architecture over quick wins
- Write code for the next person reading it, not for the person writing it
- Treat documentation and tests as part of the deliverable, not an afterthought
- Ship incrementally — small, reviewable units of work over large, opaque ones
- Correctness before optimization, always; performance work is justified by benchmarks, not intuition
